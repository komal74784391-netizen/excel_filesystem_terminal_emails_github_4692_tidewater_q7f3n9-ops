# Register field notes

- `dataset_id` — stable identifier. Do not renumber entries.
- `title` — display title.
- `candidate_repo` — repository slug to look up on our own GitHub account.
- `repository_url` — canonical project repository on our own account. Entries
  for projects that are not public yet carry no `repository_url` at all.
- `coverage` — only filled for the quarterly collection entry.
